Hoe de prioritering tot stand komt

1. Ophalen

De radar haalt eerst breed signalen op via RSS en Brave Search. Beide lopen altijd vóór filtering of scoring.

2. Datumfilter

Voor deze run is de dataset teruggebracht naar maart 2026.

  • RSS kan redelijk strak op publicatiedatum worden gefilterd.
  • Brave levert in de huidige pipeline vaak geen betrouwbare publicatiedatum mee. Daarom zijn Brave-resultaten uit deze verse run meegenomen, maar niet allemaal hard op publicatiedatum gevalideerd.

Dat betekent: inhoudelijk bruikbaar, maar niet 100% schoon op datum aan Brave-kant.

3. Filtering

Daarna gaat de ruis eruit. Een artikel blijft alleen over als het:

  • een duidelijke food-link heeft,
  • past binnen de scope groene biotech + voedseltransitie,
  • niet vooral rode biotech / farma / medisch is,
  • en niet alleen bekende overheidsinformatie herhaalt.

4. PESTLE-scoring

De radar telt keyword-hits in deze categorieën:

  • Policy
  • Economic
  • Social
  • Technology
  • Environmental
  • Policy_early (vroeg-signaalbonus)

In de huidige code wegen vooral deze zwaarder:

  • Economic = 0.30
  • Technology = 0.25
  • Policy_early = 0.40 bonus

Dat betekent in gewone taal: signalen over markt/opschaling, technologische productieroutes en vroege beleids- of marktprecedenten krijgen relatief meer gewicht.
